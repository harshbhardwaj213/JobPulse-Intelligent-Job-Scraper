# JobPulse – Intelligent Job Scraping Platform

## Overview

A Selenium-based web scraping project that extracts job listings, company details, locations, and job summaries from Indeed.

## Features

- Dynamic job scraping using Selenium
- Pagination handling
- Duplicate filtering
- CSV export
- Logging system
- Exception handling

## Tech Stack

- Python
- Selenium
- CSV
- Logging

## How to Run

pip install -r requirements.txt
python indeed_scraper_selenium.py
